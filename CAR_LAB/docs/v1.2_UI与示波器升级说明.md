# CAR LAB v1.2 - UI 与示波器升级说明

本版重点不是继续堆功能，而是把调车时最常用的界面、示波器和车型选择重新整理。

## 1. 全新主界面

- 顶部统一放置车型、连接方式、串口/TCP参数、连接状态和急停。
- 左侧改为分组导航：实时调试、车辆实验、参数与赛道、工具。
- 右侧只显示当前功能页面，避免 16 个 Tab 挤在一起。
- 切换车型时会重新加载该车型的字段映射，并自动带出推荐连接方式。

## 2. 示波器重点重做

- 三栏布局：通道选择 / 主曲线 / 数据探针。
- 支持搜索遥测字段。
- 提供速度、航向、电机、电源四组快捷通道。
- 每个通道显示实时值和单位。
- 鼠标移动到曲线上时，右侧固定显示同一时刻所有已选曲线数据，不再让浮窗挡住曲线。
- 左键设置 A/B 双游标，右侧自动计算 Δt 和各通道 Δ值。
- 支持冻结显示、跟随最新、显示时间窗口、Y自动范围、重置缩放、清除游标和清空数据。
- 支持滚轮缩放、平移，曲线采用更明显的颜色和更粗的线宽。
- 自动发现 MCU 新上传的数字遥测字段。

## 3. 车型库扩充

内置 10 个模板：

1. 内置仿真 · 双电机差速车
2. 内置仿真 · 四电机差速车
3. 通用 · 两轮差速智能车
4. 通用 · 四电机差速智能车
5. 通用 · Ackermann 舵机智能车
6. TI MSPM0 双电机智能车
7. TI MSP430 · 双电机智能车
8. STM32 · 双电机智能车
9. ESP32 · Wi-Fi 智能车
10. BLE · 无线智能车

这些模板仍使用 YAML 配置。实际车型字段不同，可以复制最接近的模板再修改。

## 4. 仿真四电机支持

仿真传输新增 front_left / rear_left / front_right / rear_right 的 RPM、Encoder、Current、PWM 遥测别名，方便测试四电机页面和一致性功能。

## 5. 原有功能保留

Speed Lab、Heading Lab、自定义 PID 环、AI 调参、电源监控、单电机实验、底盘调试、全部参数、参数方案、赛道工程、实验档案、系统诊断、协议监视器、MSP适配、串口、蓝牙串口、BLE、TCP 和仿真继续保留。

## 使用建议

第一次打开先选择“内置仿真 · 双电机差速车”，连接方式选择“仿真”，点击连接。进入示波器后先点“速度”，再在 Speed Lab 发送目标 RPM，即可体验新版曲线读取和 A/B 游标。
