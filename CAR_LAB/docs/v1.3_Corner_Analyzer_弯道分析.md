# CAR LAB v1.3 · Corner Analyzer 弯道分析器

本版本在赛道工程中新增自动入弯/出弯记录功能。

## 工作方式

弯道识别不是简单地“超过阈值次数 +1”，而是使用：

- 入弯阈值与出弯阈值分离（滞回）
- 入弯持续时间确认
- 出弯持续时间确认
- 左弯 / 右弯识别
- S 弯方向反转识别

这样可以降低传感器噪声或车辆摆动造成的重复计数。

## 支持的检测源

1. `gyro_z`：真实车辆默认推荐，单位通常为 °/s。
2. `curvature`：如果循迹算法已经能上传赛道曲率，可直接用曲率识别。
3. 自动模式：存在 curvature 时优先曲率，否则使用 gyro_z。

## 默认真实车辆参数

- 入弯角速度阈值：15 °/s
- 出弯角速度阈值：8 °/s
- 入弯确认：100 ms
- 出弯确认：150 ms

实际阈值需要根据 IMU、车辆速度和赛道调整。

## 每个弯道记录的数据

- 弯道编号
- 所属圈
- 左弯 / 右弯
- 入弯时间
- 出弯时间
- 入弯速度
- 弯中最低速度
- 出弯速度
- 弯道耗时
- 最大循迹误差
- 峰值角速度

## 圈速摘要

每一圈会额外保存该圈的入弯次数和出弯次数。如果一圈结束时仍在弯中，可能看到“入弯次数比出弯次数多 1”，这代表弯道跨越了计圈点，而不一定是识别错误。

## MCU 推荐遥测

```json
{"type":"TEL","data":{"speed":3.4,"gyro_z":28.6,"tracking_error":0.031,"battery":11.8,"lap_trigger":0}}
```

如果 MCU 还能提供曲率：

```json
{"type":"TEL","data":{"speed":3.4,"gyro_z":28.6,"curvature":0.18,"tracking_error":0.031,"battery":11.8,"lap_trigger":0}}
```

## 方向反了怎么办

车型 YAML 的 `direction_sign` 默认是 `1`。如果左弯被显示成右弯，把它改成 `-1` 即可。
