# v1.0 Unified 合并说明

本版解决“新 Live Tuning 分支与旧工程功能分开”的问题，将两条路线合并到一个程序。

## 保留/恢复

- 单电机实验、参数方案、赛道工程、MSP 适配
- 本地 AI 调参思路与实验历史数据库
- 系统/底盘诊断思路

## 新增/继续保留

- VOFA+ 风格 Speed Lab
- Heading 外环 + Yaw Rate 内环独立工作台
- ADC 电源监控和 MSP ADC 模板
- 参数修改曲线标记
- 统一 TEL/CMD/SET/GET/ACK

## 注意

AI 页是本地指标和规则分析，不是联网大模型。实车阶跃测试会造成电机动作，必须架空并完成安全确认。
