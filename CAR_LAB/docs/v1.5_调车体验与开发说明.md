
# CAR LAB v1.5 调车体验与开发说明

## 1. 示波器中文化
曲线名称现在以中文为主，协议 key 作为辅助信息。

例如：
- 目标转速 / target_rpm
- 实际转速 / actual_rpm
- 速度误差 / speed_error
- 电机 PWM / motor_pwm
- 目标航向角 / target_yaw
- 实际航向角 / yaw
- 横摆角速度 / gyro_z
- 电池电压 / battery

工作组：
- 速度
- 航向
- 角速度
- 电源
- 电机
- 循迹

## 2. 自定义环
默认是普通模式，普通调车人员不需要接触协议字段。

打开“专家模式”后，显示：
- 目标命令 key
- 目标遥测 key
- 反馈遥测 key
- 误差遥测 key
- 输出遥测 key
- Kp/Ki/Kd 参数 key

这样既方便普通调车，也方便 MCU 开发者接新控制环。

## 3. 参数状态
在线修改参数时会显示：
缓冲中 → 发送中 → 已确认 / 重试 / 回读不一致 / 暂存待重试。

## 4. 启动自检
启动时检查：
- Python 模块
- main.py
- vehicles
- requirements.txt

如果运行时仍发生异常，错误会写到：
`logs/error.log`

## 5. 快捷工作区
顶部按钮：
速度 / 航向 / 示波器 / 弯道

直接跳转到对应页面。
