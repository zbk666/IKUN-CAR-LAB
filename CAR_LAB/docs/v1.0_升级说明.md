# CAR LAB v1.0 - Live Tuning & Heading Lab

## 本次核心升级

### Speed Lab
- VOFA+ 风格的“目标值 vs 实际值”实时拟合曲线。
- Kp/Ki/Kd +/- 步进调节。
- 修改立即 SET，下位机 ACK 后继续观察曲线。
- 参数修改时间点自动在曲线上打标记。
- 显示 RX 频率、误差、输出。

### Heading Lab
角度环不再复制速度环布局，而是按串级控制设计：
- 外环：Target Yaw / Actual Yaw / Yaw Error。
- 内环：Target Yaw Rate / Gyro Z / Steering Output。
- 同时观察 Vehicle Speed。
- 内外环参数分开在线调整。
- 内置角度 -180~180 误差归一化。
- 本地规则诊断会区分“外环太激进”和“角速度内环跟不上”。

### Power Monitor
- battery / battery_raw / left_current / right_current。
- 最低电压、实时压降、低压告警。
- MSP 模板增加 ADC 分压换算、gain/offset 校准与低通滤波。

## 第一次建议
双击 install.bat，安装完成后双击 run.bat。
先连接“仿真”，进入 Speed Lab 发送 500 RPM，再进 Heading Lab 做 0° -> 30° 阶跃。
