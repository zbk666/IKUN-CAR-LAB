
# CAR LAB v1.4 调车体验说明

## 速度环
顶部直接点“速度”，进入 Speed Lab。
左侧直接改 Kp/Ki/Kd；右侧：
- 上图：Target / Actual
- 下图：Error 单独自动放大

参数修改后状态会显示：
缓冲中 → 发送中 → 已确认 / 超时重试 / 回读不一致。

## 示波器
使用“工作组”：
- 速度
- 航向
- 角速度
- 电源
- 电机
- 循迹

选择工作组后自动勾选相关通道。
鼠标放到曲线上读取同一时间点数据。
左键第一次锁定 A，第二次锁定 B，自动显示 Δt 与 Δ值。

Y轴“局部”模式用于看小误差，“全范围”用于看整体，“固定”用于固定显示范围。

## 航向环
建议同时看：
Target Yaw / Yaw / Yaw Error
Target Yaw Rate / Gyro Z / Steering Output
不要只看单条角度曲线。

## 弯道
顶部“弯道”可快速进入赛道工程。
系统自动记录入弯/出弯、左右弯、弯道耗时、速度和误差。
